# Village Wars | جنگ دهکده‌ها

یک بازی استراتژی مرورگری الهام‌گرفته از بازی‌های کلاسیک ساخت دهکده (مثل Travian / Tribal Wars).

## ویژگی‌ها

- **دهکده زیبا** با ساختمان‌های قابل ارتقا (تالار اصلی، سربازخانه، آکادمی، انبار، دیوار، بازار، منابع و ...)
- **سیستم منابع**: چوب، خاک رس، آهن، غذا + طلا
- **تولید منابع** بر اساس سطح ساختمان‌ها
- **سربازسازی**: نیزه‌دار، شمشیرزن، کماندار، سواره، منجنیق
- **پژوهش (آکادمی)** برای باز کردن نیروهای قوی‌تر و بونوس‌ها
- **نقشه جهان** با ده‌ها دهکده دیگر (AI / بربر)
- **سیستم حمله** و گزارش نبرد + غنیمت
- **خزانه**: خرید و فروش منابع با طلا
- **صف ساخت، آموزش و پژوهش**
- **تنظیمات** (صدا، سرعت بازی، زبان)
- **ذخیره محلی** + خروجی/ورودی برای انتقال بین دستگاه‌ها
- رابط کاملاً فارسی و راست‌چین

## نحوه اجرا (لوکال)

فقط فایل‌ها را با یک سرور استاتیک باز کنید:

```bash
# با پایتون
python -m http.server 8080

# یا با npx
npx serve .
```

سپس به `http://localhost:8080` بروید.

## استقرار روی Cloudflare Pages

1. این پوشه را به یک ریپازیتوری GitHub پوش کنید.
2. به [Cloudflare Pages](https://pages.cloudflare.com) بروید.
3. پروژه جدید بسازید و ریپو را متصل کنید.
4. Build settings:
   - Framework preset: `None`
   - Build command: (خالی بگذارید)
   - Output directory: `/` (یا `.`)
5. Deploy کنید.

سایت شما آماده است و روی همه دستگاه‌ها کار می‌کند.

> **نکته مهم درباره چندنفره واقعی:**  
> نسخه فعلی داده‌ها را در `localStorage` مرورگر ذخیره می‌کند (برای هر دستگاه جدا).  
> برای اینکه بازیکنان واقعی همدیگر را روی نقشه ببینند و به هم حمله کنند، نیاز به بک‌اند دارید (Cloudflare Workers + D1 یا Durable Objects).  
> ساختار کد طوری نوشته شده که اضافه کردن بک‌اند نسبتاً ساده باشد.

## ساختار فایل‌ها

```
village-wars/
├── index.html          # صفحه اصلی
├── css/style.css       # استایل‌های زیبا و مدرن
├── js/
│   ├── data.js         # تعریف ساختمان‌ها، نیروها، پژوهش‌ها
│   ├── player.js       # منطق بازیکن، منابع، صف‌ها، نبرد
│   ├── map.js          # نقشه جهان (Canvas)
│   ├── units.js        # کمکی نیروها
│   ├── ui.js           # رندر رابط کاربری
│   └── app.js          # نقطه ورود و رویدادها
└── README.md
```

## توسعه بعدی پیشنهادی

- اتصال به Cloudflare Workers + D1 برای حساب‌های واقعی و نقشه مشترک
- سیستم اتحاد (Alliance)
- پیام‌رسانی بین بازیکنان
- رویدادهای تصادفی و کوئست
- نسخه موبایل بهتر (PWA)
